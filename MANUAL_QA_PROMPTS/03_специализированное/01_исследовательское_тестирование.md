# Исследовательское тестирование (Exploratory Testing)

Промпты для организации research-сессий: чартер, стратегия поиска багов и отчёт по сессии.

> **Как использовать:** скопируйте промпт, замените плейсхолдеры в `[КВАДРАТНЫХ СКОБКАХ]`. Результат всегда проверяйте — финальное слово за тестировщиком.

---

## 1. Чартер тест-сессии

**Зачем:** получить структурированный чартер с миссией, областями исследования и критериями успеха.

**Источник:** [qa-prompt-library (106 ★)](https://github.com/tayyabakmal1/qa-prompt-library) → `manual-qa/exploratory-testing/exploratory-testing-prompts.md`, промпт «Session-Based Test Charter Creation» — переведено на русский.

```text
Составь чартер для исследовательской тест-сессии (exploratory testing charter).

Фича/область: [НАЗВАНИЕ]
Версия сборки: [НОМЕР]
Миссия: [ЧТО ИССЛЕДУЕМ]
Длительность: [ТАЙМ-БОКС, обычно 60–120 минут]

Чартер должен включать:
- чёткую формулировку миссии;
- области для исследования;
- тест-идеи и эвристики для применения;
- риски для проверки;
- необходимые данные и инструменты;
- критерии успеха сессии.

Оформи как шаблон чартера сессии.
```

---

## 2. Стратегия поиска багов (Bug Hunting)

**Зачем:** сосредоточить ограниченное время сессии на самых рискованных местах приложения.

**Источник:** [qa-prompt-library (106 ★)](https://github.com/tayyabakmal1/qa-prompt-library) → `manual-qa/exploratory-testing/exploratory-testing-prompts.md`, промпт «Bug Hunting Strategy» — переведено на русский.

```text
Составь стратегию поиска багов (bug hunting).

Приложение: [НАЗВАНИЕ]
Целевая область: [КОНКРЕТНАЯ ЧАСТЬ СИСТЕМЫ]
Известные проблемы: [СПИСОК]
Доступное время: [ДЛИТЕЛЬНОСТЬ]

Предоставь:
- области повышенного риска, на которых сосредоточиться;
- эвристики тестирования (SFDPOT, FEW HICCUPS и т.д.);
- граничные условия для проверки;
- сценарии «догадки об ошибках» (error guessing);
- техники исследовательского тестирования;
- шаблон заметок по ходу сессии.
```

---

## 3. Отчёт по тест-сессии

**Зачем:** зафиксировать результаты сессии: что проверено, что найдено, что осталось за кадром.

**Источник:** [qa-prompt-library (106 ★)](https://github.com/tayyabakmal1/qa-prompt-library) → `manual-qa/exploratory-testing/exploratory-testing-prompts.md`, промпт «Exploratory Test Session Report» — переведено на русский.

```text
Составь шаблон отчёта по исследовательской тест-сессии.

Данные сессии:
- тестировщик: [ИМЯ]
- чартер: [ОПИСАНИЕ]
- длительность: [ВРЕМЯ]
- сборка: [ВЕРСИЯ]

Включи секции:
- что тестировалось;
- заметки и наблюдения по ходу;
- найденные баги (с severity);
- возникшие вопросы;
- области, которые остались непокрытыми;
- дальнейшие действия;
- метрики сессии (покрытие, баги, время).
```
