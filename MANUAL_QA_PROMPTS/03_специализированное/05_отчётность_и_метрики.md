# Отчётность и метрики

Промпты для отчётов руководству и анализа качества релизов: executive summary, решение GO/NO-GO, тренды метрик.

> **Как использовать:** скопируйте промпт, замените плейсхолдеры в `[КВАДРАТНЫХ СКОБКАХ]`. Результат всегда проверяйте — финальное слово за тестировщиком.

---

## 1. Executive Summary по релизу

**Зачем:** сжатый отчёт для руководства на языке бизнеса — без тестировочного жаргона.

**Источник:** [«15 промптов ChatGPT для QA», Хабр](https://habr.com/ru/articles/986376/) — структура промпта воспроизведена на русском.

```text
Ты — QA-лид. Составь executive summary по результатам тестирования релиза.

Входные данные (статистика из Jira/TestRail): [ВСТАВИТЬ ЧИСЛА]

Структура отчёта:
1. Резюме для руководства — 3–5 предложений: состояние релиза одним абзацем.
2. Ключевые метрики: выполнено тест-кейсов, баги по severity, pass rate, отклонение от плана.
3. Топ-3 критических бага — влияние на бизнес одним предложением на каждый.
4. Риски релиза.
5. Рекомендация GO / NO-GO с обоснованием.
6. Уроки (lessons learned) — 2–3 пункта.

Тон — деловой, без жаргона, числа — в процентах и штуках.
```

## 2. Оценка готовности релиза (GO/NO-GO)

**Зачем:** структурировать решение о выпуске: риски, условия запуска, меры смягчения.

**Источник:** [qa-prompt-library (106 ★)](https://github.com/tayyabakmal1/qa-prompt-library) → `ai-assisted-qa/release-quality-prompts.md`, промпт «Go/No-Go Decision Support» — переведено на русский.

```text
Помоги оценить готовность релиза.

Версия релиза: [ВЕРСИЯ]
Дата релиза: [ДАТА]
Покрытие тестами: [ПРОЦЕНТ]
Открытые дефекты: [КОЛИЧЕСТВО ПО SEVERITY]
Проходимость тестов (pass rate): [ПРОЦЕНТ]
Известные проблемы: [ОПИСАНИЕ]

Предоставь:
- оценку рисков;
- анализ метрик качества;
- рекомендацию GO / NO-GO с обоснованием;
- стратегии смягчения выявленных рисков;
- условия, при которых релиз можно выпускать.
```

## 3. Тренд-анализ метрик качества

**Зачем:** увидеть динамику по неделям, понять причины негативных трендов и получить прогноз.

**Источник:** [«15 промптов ChatGPT для QA», Хабр](https://habr.com/ru/articles/986376/) — структура промпта воспроизведена на русском.

```text
Ты — QA-аналитик. Проведи тренд-анализ метрик качества.

Входные данные — CSV по неделям: количество багов, распределение по severity, время исправления, доля регрессий: [ВСТАВИТЬ ДАННЫЕ]

Задачи:
1. Тренд-анализ по каждой метрике.
2. Бенчмаркинг: сравнение с прошлым кварталом.
3. Первопричины негативных трендов (root cause).
4. Прогноз на месяц вперёд — 3 сценария (оптимистичный, базовый, пессимистичный).
5. Топ-3 рекомендации по улучшению.

В конце опиши 2–3 графика, которые стоит построить по этим данным, с осями и выводами.
```
