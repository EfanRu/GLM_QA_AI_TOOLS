# SQL и регулярные выражения

Промпты-«инструменты» для проверки данных и валидации: SQL-терминал, генератор regex и проверка целостности БД.

> **Как использовать:** скопируйте промпт, замените плейсхолдеры в `[КВАДРАТНЫХ СКОБКАХ]`. Результат всегда проверяйте — финальное слово за тестировщиком.

---

## 1. SQL-терминал

**Зачем:** репетиция SQL-запросов для проверки данных без доступа к реальной БД — модель играет роль терминала.

**Источник:** промпт «SQL терминал» из [awesome-chatgpt-prompts-ru](https://github.com/smartmanru/awesome-chatgpt-prompts-ru) — русскоязычной версии репозитория [f/prompts.chat](https://github.com/f/prompts.chat) (100k+ ★). Текст приведён дословно (исправлена одна опечатка в скобках).

```text
Я хочу, чтобы вы выступили в роли SQL терминала перед примером базы данных. База данных содержит таблицы с именами "Продукты", "Пользователи", "Заказы" и "Поставщики". Я буду вводить запросы, а вы будете отвечать тем, что покажет терминал. Я хочу, чтобы вы ответили таблицей результатов запроса в одном блоке кода, и больше ничего. Не пишите объяснений. Не вводите команды, пока я не проинструктирую вас об этом. Когда мне нужно сказать вам что-то по-английски, я буду делать это в фигурных скобках {как здесь}. Моя первая команда — 'SELECT TOP 10 * FROM Products ORDER BY Id DESC'
```

## 2. Генератор регулярных выражений

**Зачем:** быстро получить regex для валидации полей или поиска по логам — в готовом к вставке виде.

**Источник:** промпт «Генератор регулярных выражений» из [awesome-chatgpt-prompts-ru](https://github.com/smartmanru/awesome-chatgpt-prompts-ru) — русскоязычной версии репозитория [f/prompts.chat](https://github.com/f/prompts.chat) (100k+ ★). Текст приведён дословно.

```text
Я хочу, чтобы вы выступили в роли генератора регулярных выражений. Ваша роль заключается в генерации регулярных выражений, которые соответствуют определенным шаблонам в тексте. Вы должны предоставить регулярные выражения в формате, который можно легко скопировать и вставить в текстовый редактор с поддержкой regex или язык программирования. Не пишите объяснений или примеров того, как работают регулярные выражения; просто предоставьте только сами регулярные выражения. Моя первая задача — сгенерировать регулярное выражение, которое соответствует адресу электронной почты.
```

## 3. Проверка целостности данных в БД

**Зачем:** системно проверить ссылочную, сущностную и доменную целостность после миграций и изменений схемы.

**Источник:** [qa-prompt-library (106 ★)](https://github.com/tayyabakmal1/qa-prompt-library) → `automation-qa/database-testing/sql-testing-prompts.md`, промпт «Data Integrity Testing» — переведено на русский.

```text
Составь тест-кейсы для проверки целостности данных.

База данных: [НАЗВАНИЕ]
Критичные таблицы: [СПИСОК]

Сценарии проверки:
1. Ссылочная целостность (Referential Integrity)
   - внешние ключи не дают создать «осиротевшие» записи;
   - каскадное удаление/обновление работает как задумано;
   - связи родитель–потомок корректны.
2. Сущностная целостность (Entity Integrity)
   - первичные ключи уникальны и не null;
   - механизмы предотвращения дубликатов работают;
   - unique-ограничения валидны.
3. Доменная целостность (Domain Integrity)
   - ограничения по типам данных;
   - check-ограничения;
   - значения по умолчанию;
   - NOT NULL-ограничения.
4. Пользовательская целостность
   - валидация бизнес-правил;
   - работа триггеров;
   - кастомные ограничения.

Для каждого сценария сгенерируй SQL-скрипты: подготовка данных, выполнение, проверка результата.
```
