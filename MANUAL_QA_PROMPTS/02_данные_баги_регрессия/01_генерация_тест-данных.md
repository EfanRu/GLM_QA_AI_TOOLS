# Генерация тест-данных

Промпты для массовой генерации данных: по схеме, под конкретное поле ввода и под проверку локализации.

> **Как использовать:** скопируйте промпт, замените плейсхолдеры в `[КВАДРАТНЫХ СКОБКАХ]`. Результат всегда проверяйте — финальное слово за тестировщиком.

---

## 1. Тестовые данные по JSON-схеме

**Зачем:** получить наборы данных всех шести классов — от happy path до security-пейлоадов — в готовом к импорту виде.

**Источник:** [«15 промптов ChatGPT для QA», Хабр](https://habr.com/ru/articles/986376/) — структура промпта воспроизведена на русском.

```text
Сгенерируй тестовые данные в формате JSON для модуля.

JSON-схема или описание полей: [ВСТАВИТЬ СХЕМУ]

Покрой 6 типов сценариев:
1. Happy path — 3–5 корректных записей.
2. Граничные значения (мин/макс длины, диапазоны чисел).
3. Негативные данные (невалидные типы, пустые значения, пропущенные обязательные поля).
4. Security-пейлоады (SQL-инъекции, XSS).
5. i18n — кириллица, иероглифы, RTL-текст, эмодзи.
6. Объёмный набор для нагрузочных проверок (1000+ записей).

Для каждого набора укажи: назначение и ожидаемый результат валидации.
```

---

## 2. Тестовые данные для поля ввода

**Зачем:** исчерпывающий набор данных под одно поле — по чек-листу «регистр/пробелы/спецсимволы/инъекции».

**Источник:** [«5 мощных промптов ChatGPT для тестировщиков», QaRocks](https://qarocks.ru/chatgpt-prompts-for-qa/) — структура промпта воспроизведена на русском.

```text
Сгенерируй полный набор тестовых данных для этого поля ввода: [ПОЛЕ И ПРАВИЛА ВАЛИДАЦИИ]

Проверь: чувствительность к регистру; пробелы в начале и в конце; спецсимволы; только цифры и только буквы; минимальную и максимальную длину; пустой ввод; дубликаты; юникод и «сложные» строки; null-символы; попытки инъекций.

Вывод — таблица: «Значение | Что проверяем | Ожидаемый результат».
```

## 3. Тестовые данные для проверки локализации

**Зачем:** данные под мультиязычные проверки — RTL, форматы дат/валют, расширение текста в UI.

**Источник:** [qa-prompt-library (106 ★)](https://github.com/tayyabakmal1/qa-prompt-library) → `ai-assisted-qa/test-data-generation-prompts.md`, промпт «Localization Test Data» — переведено на русский.

```text
Сгенерируй тестовые данные для проверки локализации.

Языки и локали: [СПИСОК]
Типы данных: [ТЕКСТ / ДАТЫ / ЧИСЛА / ВАЛЮТА]
Особые случаи: [RTL-ЯЗЫКИ, СПЕЦСИМВОЛЫ И Т.П.]

Сгенерируй:
- тексты на разных языках, включая RTL-языки (арабский, иврит);
- форматы дат, валют, чисел, адресов и телефонов для разных локалей;
- длинные строки для проверки расширения текста в интерфейсе;
- примеры отсутствующих переводов (как должно выглядеть fallback-поведение).
```
