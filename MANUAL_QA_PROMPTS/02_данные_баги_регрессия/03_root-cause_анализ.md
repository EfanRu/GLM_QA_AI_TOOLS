# Root Cause Analysis

Промпты для разбора уже найденных багов: от общего поиска причин до 5 Whys и диаграммы Ишикавы.

> **Как использовать:** скопируйте промпт, замените плейсхолдеры в `[КВАДРАТНЫХ СКОБКАХ]`. Результат всегда проверяйте — финальное слово за тестировщиком.

---

## 1. Общий анализ первопричины

**Зачем:** получить ранжированный список гипотез о причине бага и план проверки каждой.

**Источник:** [qa-prompt-library (106 ★)](https://github.com/tayyabakmal1/qa-prompt-library) → `manual-qa/bug-reporting/root-cause-prompts.md`, промпт «General Root Cause Analysis» — переведено на русский.

```text
Помоги проанализировать первопричину (root cause) этого бага.

Описание бага: [ОПИСАНИЕ]
Симптомы: [ЧТО НАБЛЮДАЕМ]
Когда возникает: [УСЛОВИЯ]
Затронутые компоненты: [СПИСОК]
Недавние изменения: [ЧТО МЕНЯЛОСЬ]

Предоставь:
- возможные первопричины, ранжированные по вероятности;
- методику анализа;
- вопросы для дальнейшего расследования;
- предлагаемые шаги отладки;
- как подтвердить найденную причину.
```

---

## 2. Анализ «5 почему» (5 Whys)

**Зачем:** дойти до системной причины проблемы, а не остановиться на симптоме.

**Источник:** [qa-prompt-library (106 ★)](https://github.com/tayyabakmal1/qa-prompt-library) → `manual-qa/bug-reporting/root-cause-prompts.md`, промпт «5 Whys Analysis» — переведено на русский.

```text
Проведи анализ первопричины методом «5 почему» (5 Whys).

Формулировка проблемы: [ОПИСАНИЕ]

Проведи меня по цепочке:
1. Почему возникла эта проблема?
2. Почему это произошло?
3. Почему это произошло?
4. Почему это произошло?
5. Почему это произошло?

После каждой ступени предложи свой ответ и спроси моё подтверждение, прежде чем идти глубже.

В конце дай:
- формулировку первопричины;
- предупреждающие меры (preventive measures);
- улучшения процесса.
```

## 3. Диаграмма Ишикавы (Fishbone)

**Зачем:** разложить возможные причины по шести категориям и найти приоритет для расследования.

**Источник:** [qa-prompt-library (106 ★)](https://github.com/tayyabakmal1/qa-prompt-library) → `manual-qa/bug-reporting/root-cause-prompts.md`, промпт «Fishbone/Ishikawa Diagram Analysis» — переведено на русский.

```text
Помоги построить анализ по диаграмме Ишикавы (fishbone) для этого дефекта.

Проблема: [ОПИСАНИЕ]

Проанализируй возможные причины по категориям:
- Люди (человеческий фактор);
- Процессы (workflow, процедуры);
- Технологии (инструменты, системы);
- Окружение (инфраструктура, условия);
- Данные (входные данные, качество);
- Дизайн (архитектура, требования).

Для каждой категории определи:
- возможные сопутствующие факторы;
- наиболее вероятные причины;
- приоритет расследования.
```
