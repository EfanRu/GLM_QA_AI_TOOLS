# MANUAL_QA_PROMPTS — каталог промптов для ручных тестировщиков

Подборка проверенных промптов под повседневные задачи manual QA. Все промпты взяты из источников с подтверждённой репутацией (GitHub-библиотеки со звёздами, популярные статьи) и адаптированы на русский язык. Оригиналы — по ссылкам в каждом файле.

## Как пользоваться

1. Выберите файл по задаче — карта каталога ниже.
2. Скопируйте промпт и замените плейсхолдеры в `[КВАДРАТНЫХ СКОБКАХ]` на данные вашего проекта.
3. Чем больше конкретики на входе (правила, форматы, ограничения) — тем качественнее ответ.
4. Результат всегда проверяйте: LLM может «галлюцинировать», финальное слово за тестировщиком.

## Универсальная роль «QA-тестировщик»

Стартовый промпт, с которого можно начинать любую сессию в чате (адаптация промпта «Software Quality Assurance Tester» из репозитория [f/prompts.chat](https://github.com/f/prompts.chat) — 100k+ ★):

```text
Я хочу, чтобы ты выступил в роли тестировщика ПО (QA) для нового приложения. Твоя задача — проверять функциональность и производительность приложения на соответствие требованиям. Ты должен находить баги, ошибки и несоответствия и подробно описывать их: шаги воспроизведения, ожидаемый и фактический результат, рекомендации по исправлению. Не добавляй субъективных оценок — только факты. Первая задача: проверь функциональность входа (логина) в новом приложении.
```
