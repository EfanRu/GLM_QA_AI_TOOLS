# Генерация тест-кейсов

Промпты для быстрого составления функциональных тест-кейсов по фиче, сущности или форме.

> **Как использовать:** скопируйте промпт, замените плейсхолдеры в `[КВАДРАТНЫХ СКОБКАХ]`. Результат всегда проверяйте — финальное слово за тестировщиком.

---

## 1. Тест-кейсы по описанию фичи

**Зачем:** получить полный набор кейсов по фиче — от happy path до альтернативных потоков — в едином формате.

**Источник:** [qa-prompt-library (106 ★)](https://github.com/tayyabakmal1/qa-prompt-library) → `manual-qa/test-case-creation/functional-prompts.md`, промпт «Feature-Based Test Case Generation» — переведено на русский.

```text
Составь подробные функциональные тест-кейсы для фичи [НАЗВАНИЕ_ФИЧИ].

Описание фичи: [ОПИСАНИЕ]
Пользовательская история: [USER STORY]
Критерии приёмки: [КРИТЕРИИ]

Покрой:
- сценарии happy path;
- альтернативные потоки;
- валидацию входных данных;
- ожидаемые результаты;
- предусловия и постусловия.

Каждый тест-кейс оформи с полями: ID, Название, Предусловия, Шаги, Ожидаемый результат, Приоритет.
```

---

## 2. Тест-кейсы для CRUD-операций

**Зачем:** системно проверить создание/чтение/обновление/удаление сущности — типовая дыра в покрытии.

**Источник:** [qa-prompt-library (106 ★)](https://github.com/tayyabakmal1/qa-prompt-library) → `manual-qa/test-case-creation/functional-prompts.md`, промпт «CRUD Operations Testing» — переведено на русский.

```text
Составь функциональные тест-кейсы для CRUD-операций над сущностью [НАЗВАНИЕ_СУЩНОСТИ].

Поля сущности: [СПИСОК ПОЛЕЙ И ТИПОВ]
Бизнес-правила: [ОПИСАНИЕ ПРАВИЛ]

Сгенерируй тест-кейсы для:
- Create: валидные и невалидные данные, обязательные поля, значения по умолчанию;
- Read: одна запись, список записей, фильтрация, сортировка;
- Update: частичное обновление, полное обновление, конкурентное обновление;
- Delete: удаление одной записи, массовое удаление, soft delete, каскадные эффекты.
```

---

## 3. Тест-кейсы для валидации формы

**Зачем:** ничего не пропустить в формах — от обязательных полей до перекрёстной валидации.

**Источник:** [qa-prompt-library (106 ★)](https://github.com/tayyabakmal1/qa-prompt-library) → `manual-qa/test-case-creation/functional-prompts.md`, промпт «Form Validation Testing» — переведено на русский.

```text
Составь тест-кейсы для проверки валидации формы.

Форма: [НАЗВАНИЕ_ФОРМЫ]
Поля и правила валидации: [СПИСОК ПОЛЕЙ С ПРАВИЛАМИ]

Создай тест-кейсы для:
- проверки обязательных полей;
- проверки типа данных;
- проверки формата (email, телефон, дата и т.д.);
- ограничений длины;
- обработки спецсимволов;
- перекрёстной валидации (зависимости между полями);
- состояния кнопки отправки (активна/неактивна).
```
